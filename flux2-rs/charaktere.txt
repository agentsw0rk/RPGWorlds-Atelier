#   slug | Name | Beschreibung (deutsch, für dich) | Prompt (englisch, fürs Modell)

# Modell bekommt ausschließlich den Prompt — dahinter hängt token.sh Pose und
# Stil. Zeilen mit # und leere Zeilen werden übersprungen.

# hochgewachsen, gefiedert, geschuppt, gehörnt, vierbeinig, winzig. Bei einem
# 138x244-Token ist die Umrisslinie das, was man auf der Karte erkennt.
