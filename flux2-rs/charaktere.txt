# Charakterliste für scripts/batch.sh
#
# Format je Zeile, mit | getrennt:
#   slug | Name | Beschreibung (deutsch, für dich) | Prompt (englisch, fürs Modell)
#
# Der slug wird zum Dateinamen. Die Beschreibung liest nur der Mensch, das
# Modell bekommt ausschließlich den Prompt — dahinter hängt token.sh Pose und
# Stil. Zeilen mit # und leere Zeilen werden übersprungen.
#
# Die Auswahl deckt bewusst sehr verschiedene Silhouetten ab: gedrungen und
# hochgewachsen, gefiedert, geschuppt, gehörnt, vierbeinig, winzig. Bei einem
# 138x244-Token ist die Umrisslinie das, was man auf der Karte erkennt.
#
# Bei bekannten Figuren steht der Name links, im Prompt aber nur das Aussehen.
# Das Modell kennt die Namen nicht — "Drizzt" erzeugt nichts, "white-haired dark
# elf ranger with twin scimitars" erzeugt genau ihn. Wer eine Figur anders in
# Erinnerung hat, ändert schlicht die rechte Spalte.
