# Ortsliste für scripts/location-batch.sh
#
# Format je Zeile, mit | getrennt:
#   slug | Name | Beschreibung (deutsch, für dich) | Prompt (englisch, fürs Modell)
#
# Der slug wird zum Dateinamen. Die Beschreibung liest nur der Mensch, das
# Modell bekommt ausschließlich den Prompt — location.sh hängt Stil (sepiafarbene
# Feder-Tusche-Gravur, Reisejournal) automatisch an. Zeilen mit # und leere
# Zeilen werden übersprungen.
#
# Bei bekannten Orten steht der Name links, im Prompt aber nur das Aussehen.
# Das Modell kennt die Namen nicht — "Waterdeep" erzeugt nichts, "sprawling
# harbor city climbing terraced cliffs" erzeugt etwas Passendes. Wer einen Ort
# anders in Erinnerung hat, ändert schlicht die rechte Spalte.
#
# Die Auswahl deckt bewusst sehr verschiedenes Terrain und Architektur ab:
# Küste, Wüste, Sumpf, Gebirge, Dschungel, Unterreich, Andersweltlich. Bei
# einer 1024x512-Illustration ist die Silhouette der Landschaft das, was das
# Bild trägt — zwei Dörfer mit Fachwerkhäusern unterscheiden sich sonst kaum.
